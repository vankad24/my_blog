# Project Overview

Этот проект - веб приложение для ведения блогов и публикации постов, построенный на Laravel. 

Для запуска проекта выполни:
- `php artisan serve`

**Key Technologies:**
- **Backend:** PHP ^8.2, Laravel ^12.0
- **Frontend:** Vite, Tailwind CSS
- **Database:** postgresql

This project follows the standard Laravel application structure, which is based on the Model-View-Controller (MVC) architectural pattern.
### Key Directories

-   **`app/`**: This is the core of the application.
    -   **`Http/Controllers/`**: Contains the controllers that handle user requests and retrieve data from models to pass to views.
    -   **`Models/`**: Contains all the Eloquent model classes. Each model represents a table in the database.
    -   **`Providers/`**: Contains the service providers for bootstrapping services, events, and other parts of the application.
    -   **`Events/`**: Contains event classes that can be dispatched to notify other parts of the application that a given action has occurred.
    -   **`Listeners/`**: Contains listener classes that handle the events.
    -   **`Policies/`**: Contains authorization policy classes for the application's models.

-   **`bootstrap/`**: Contains the `app.php` file which bootstraps the framework. It also contains a `cache` directory for framework performance optimization.

-   **`config/`**: Contains all of the application's configuration files.

-   **`database/`**: Contains the database migrations, model factories, and seeds.
    -   **`factories/`**: Contains model factories for generating test data.
    -   **`migrations/`**: Contains the database schema migrations.
    -   **`seeders/`**: Contains database seeder classes for populating the database.

-   **`public/`**: The web server's document/web root. It contains the `index.php` file, which is the entry point for all requests entering the application. This directory also houses assets like images, JavaScript, and CSS.

-   **`resources/`**: Contains the views, raw assets (CSS, JS), and language files.
    -   **`css/`**: Contains the application's CSS files.
    -   **`js/`**: Contains the application's JavaScript files.
    -   **`views/`**: Contains the application's views, written in Blade templating language (`.blade.php`).

-   **`routes/`**: Contains all of the route definitions for the application.
    -   **`web.php`**: Contains routes for the web interface.
    -   **`api.php`**: Contains routes for the API.
    -   **`console.php`**: Contains console command definitions.
    -   **`auth.php`**: Contains authentication-related routes.

-   **`storage/`**: Contains compiled Blade templates, file-based sessions, file caches, and other files generated by the framework.

-   **`tests/`**: Contains the automated tests.
    -   **`Feature/`**: Contains feature tests.
    -   **`Unit/`**: Contains unit tests.

-   **`vendor/`**: Contains the Composer dependencies.
